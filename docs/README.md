# Syntra GitHub Pages Site

This directory contains the static website files for the Syntra GitHub Pages site.

## Files Structure

- `index.html` - Main landing page for the Syntra app
- `privacy-policy.html` - Privacy policy page (Play Store compliant)
- `styles.css` - Main stylesheet with responsive design
- `privacy-styles.css` - Additional styles for privacy policy page
- `404.html` - Custom 404 error page
- `favicon.png` - App icon for the website
- `README.md` - This documentation file

## Features

### Landing Page
- Responsive design that works on all devices
- Hero section with app introduction
- Features grid highlighting key app capabilities
- About section with additional details
- Call-to-action buttons for Play Store download
- Mobile-friendly navigation

### Privacy Policy
- HTML version of the markdown privacy policy
- Structured sections for easy reading
- Mobile-responsive layout
- Compliant with Play Store requirements
- Easy navigation back to main site

### Design
- Clean, modern design using the app's brand colors
- Fully responsive for mobile and desktop
- Accessible navigation and focus states
- Print-friendly styles
- Smooth scrolling and transitions

## GitHub Pages Setup

This site is designed to be served from the `docs/` folder on the main branch or from a `gh-pages` branch.

### Recommended Setup:
1. Enable GitHub Pages in repository settings
2. Choose "Deploy from a branch"
3. Select either:
   - Main branch / docs folder, or
   - gh-pages branch / root
